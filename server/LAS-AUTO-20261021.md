# Automatic LAS generation — 21 October 2026

## Behavior

- Completing curriculum or existing-lesson setup now generates editable LAS starter activities automatically, without pressing Generate or importing AI JSON. A 450 ms delay combines consecutive selection changes; changing the setup cancels pending work. Incomplete setup does not generate a new draft.
- Untouched generated starters follow competency, session and activity-type changes. Canonical setup keys prevent repeat generation caused by unrelated renders, preview modes, or asynchronous page counting.
- Editing, saving, marking review, exporting, opening an AI prompt, importing an AI response, or opening an existing saved LAS protects the draft. Setup changes then show an explicit stale-setup notice. **Apply changed setup** / **Regenerate LAS** displays an in-page confirmation with **Replace draft with new activities** and **Keep current draft**. No browser confirmation pop-up is used.
- Existing exact competency snapshots, separate teacher answers, save/reopen, optional AI prompt/import and combined three-page export limits remain intact. Starter content is still teacher-reviewed scaffolding, not a live AI-provider call or factual certification.
