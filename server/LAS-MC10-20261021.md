# LAS multiple-choice minimum — 21 October 2026

Newly generated **Multiple choice** LAS contains at least 10 questions **in total across selected sessions**, not 10 per session. Default distribution is 10; 5+5; 4+3+3; or 3+3+2+2. More questions are retained if needed to cover all selected competencies. Mixed and other activity types are unchanged.

Each new pure-MC record carries optional `minimumMultipleChoiceQuestions: 10` metadata. Save/export/import validation enforces the minimum for these records. Older saved LAS without that field remains readable and unchanged until explicitly regenerated. Removing a question at the minimum is disabled; Add activity in MC mode creates an editable MC item with four options. Changing a question's type below the minimum shows the deficit and blocks final save/export until repaired.

Ten distinct reasoning starters replace repetition of one MC template. Answer positions vary, and teacher keys derive directly from each task's options/correct index. These remain explicitly teacher-reviewed scaffolds; optional AI enhancement requests distinct topic-specific questions with the same IDs/counts and exact official competency snapshots. No external AI call, provider configuration or secret was added.

Questions use continuous numbering across sessions in editor, student preview, Word/PDF/Print and teacher guide. Compact MC export omits redundant per-item headings and uses a single answer field. The combined three-page limit, 10 pt body text, separate teacher answers, source snapshots and automatic-generation draft protection remain intact.
