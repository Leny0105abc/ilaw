# LAS setup and three-page limit — 21 October 2026

## Implemented

- Create LAS now defaults to curriculum setup: Grade 7–10, Learning Area, Term, Week, then all available competencies for that selection, with individual checkboxes and Select all. Choices reuse the existing curriculum, including GMRC and one-term ICT specializations; unavailable terms/weeks are not invented.
- Existing lesson-linked creation remains available. Saved LAS retains an independent source/competency snapshot, including when its source is no longer in the lesson library.
- Teachers can include any combination of Sessions 1–4. Curriculum-based starter tasks distribute every selected competency across those sessions; selecting just one session still includes every selected competency.
- Activity types: multiple choice, matching, essay, identification, true/false, performance, or mixed. Multiple-choice options and correct option are editable separately; the student copy never includes the teacher key. JSON import validates all four options and the answer index, preserves task IDs/types, and keeps the old draft if import fails.
- The student LAS and separate teacher guide each have a maximum of three A4 pages for **all selected sessions together**, not three pages per session. A shared conservative text layout drives editable Word, PDF and Print. Body text remains 10 pt and headings 12 pt. Content is never truncated or silently omitted. Oversized drafts remain editable, but save, import and exports reject an over-limit result with a clear message.
- Starters are labeled as scaffolds requiring teacher adaptation; optional ChatGPT/Gemini/Copilot prompts request actual topic-specific activities, brief notes, preserved official wording, and a combined three-page budget. No automatic external AI calls or new API keys.
